# Browser Games

Browser-based speech and language games used as interaction prototypes.

- `maze_craze_v1` - earlier maze version
- `maze_craze_v2` - newer maze version
- `Brick Spell` - spelling game using Kenney toy-brick assets
- `Coin Word Hunt` - word-hunt platformer using the standard tileset
- `Word Hunt Gallery` - shooting-gallery word game

Open each game's `index.html` in a modern browser. No Python environment or
model download is required.

The non-maze games load shared sprites from `New folder/` using relative paths.
Keep `New folder` next to the game folders when copying or moving them.
