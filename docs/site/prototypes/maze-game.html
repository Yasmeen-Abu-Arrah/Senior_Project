Maze Craze — Gamification Layer

Browser-Based Speech Therapy Game (Phaser 3)

Overview

Maze Craze is the gamification layer of the rehabilitation platform. It wraps speech therapy exercises inside an engaging, browser-based maze game built with Phaser 3 — a professional HTML5 game framework.

Children navigate a maze character to collect coins and reach the goal. The game is designed as a reward wrapper around therapy sessions — correct pronunciation unlocks movement or rewards, creating positive reinforcement loops.

Two versions exist: v1 (classic grid maze) and v2 (enhanced with assets and improved UI).

Gamification Rationale

NoteWhy Games?

Research in pediatric speech therapy consistently shows that intrinsic motivation dramatically improves therapy adherence and generalization. Children who play while practicing show 2-3x higher session engagement compared to drill-based approaches.

Key design principles: - Immediate feedback — visual/audio rewards on correct production - Progressive difficulty — maze complexity increases with performance - Character selection — agency and personalization increase buy-in - Zero reading required — icon-based UI accessible to preliterate children

Core Game Logic

// --- Character Selection Scene ---
class CharacterSelectScene extends Phaser.Scene {
    constructor() { super('CharacterSelectScene'); }

    preload() {
        // Generate colored square sprites procedurally (no external assets needed)
        this.createSquareTexture('hero_blue',  0x3498db);
        this.createSquareTexture('hero_red',   0xe74c3c);
        this.createSquareTexture('hero_green', 0x2ecc71);
    }

    create() {
        const options = ['hero_blue', 'hero_red', 'hero_green'];
        const names   = ['Aqua Knight', 'Crimson Rogue', 'Jade Ranger'];
        this.selectedKey = 'hero_blue';

        options.forEach((key, index) => {
            const xPos = 120 + (index * 120);
            const char = this.add.sprite(xPos, 200, key)
                             .setInteractive()
                             .setScale(1.5);

            char.on('pointerdown', () => {
                this.selectedKey = key;
                // Update selection indicator
            });
        });

        // Start button launches GameScene with selected character
        this.add.rectangle(240, 320, 220, 50, 0x27ae60)
            .setInteractive()
            .on('pointerdown', () => {
                this.scene.start('GameScene', { heroKey: this.selectedKey });
            });
    }
}

TipIntegration Tip

To connect Maze Craze with the speech modules, add a WebSocket listener in game.js that receives a “correct” signal from the Python backend (Gradio + WebSocket), then triggers the player’s movement reward animation.

## Scene Architecture (Phaser 3)

The game uses Phaser's **Scene Manager** to separate concerns:

```{mermaid}
stateDiagram-v2
    [*] --> CharacterSelectScene
    CharacterSelectScene --> GameScene : Player selects character
    GameScene --> GameScene : Navigate maze, collect coins
    GameScene --> GameOverScene : Reach goal tile (3)
    GameOverScene --> CharacterSelectScene : Restart
```
